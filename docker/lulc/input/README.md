# How to create input data volumes

Input will need to be uploaded to DockerHub following both sets of instructions because data volumes are mounted to Docker and Apptainer differently.

## Stage the data

* Create a working directory
* Under the working directory, create directories stage/wrf and stage/obs to stage WRF and observation data respectively
* Add the observation data files to the stage/obs staging directories
* Subset the WRF data to remove fields that are not used by the use cases.
* Stage both ctl and dfw4x WRF simulations

### Subset WRF data

This assumes that the full WRF files are in a directory called full/wrf and
the stage/wrf directory already exists.
Subdirectories under each called ctl and dfw4x should also exist to stage the WRF files for each simulation.

### Subset hourly files to include RAINC, RAINNC, REFD_MAX, HAILNC, HAIL_MAX2D, and dimension variables

```
mkdir -p stage/wrf/ctl
mkdir stage/wrf/dfw4x

# for ctl simulation
for f in full/wrf/ctl/wrfout_d03_2017-07-0*00.morr*
do
    echo ncks -v Times,XLAT,XLONG,RAINC,RAINNC,REFD_MAX,HAILNC,HAIL_MAX2D $f stage${f:4}
    ncks -v Times,XLAT,XLONG,RAINC,RAINNC,REFD_MAX,HAILNC,HAIL_MAX2D $f stage${f:4}
done

# for dfw4x simulation
for f in full/wrf/dfw4x/wrfout_d03_2017-07-0*00.morr*
do
    echo ncks -v Times,XLAT,XLONG,RAINC,RAINNC,REFD_MAX,HAILNC,HAIL_MAX2D $f stage${f:4}
    ncks -v Times,XLAT,XLONG,RAINC,RAINNC,REFD_MAX,HAILNC,HAIL_MAX2D $f stage${f:4}
done

```

### Subset 10 minute files to include RAINC, RAINNC, HAILNC, and dimension variables

```
# for ctl simulation
for minutes in 10 20 30 40 50
do
    for f in full/wrf/ctl/wrfout_d03_2017-07-0*${minutes}.morr*
    do
        echo ncks -v Times,XLAT,XLONG,RAINC,RAINNC,HAILNC $f stage${f:4}
        ncks -v Times,XLAT,XLONG,RAINC,RAINNC,HAILNC $f stage${f:4}
    done
done

# for dfw4x simulation
for minutes in 10 20 30 40 50
do
    for f in full/wrf/dfw4x/wrfout_d03_2017-07-0*${minutes}.morr*
    do
        echo ncks -v Times,XLAT,XLONG,RAINC,RAINNC,HAILNC $f stage${f:4}
        ncks -v Times,XLAT,XLONG,RAINC,RAINNC,HAILNC $f stage${f:4}
    done
done
```

### Rename WRF files to match format generated by WRF

This is done to be consistent across runs that pull WRF output from DockerHub
and runs that generate WRF output locally.
The files on Casper were named **wrfout_d03_2017-07-03_1520.morr300.nc**
while the files generated by WRF are named **wrfout_d03_2017-07-03_15:20:00**

```
cd stage/wrf/dfw4x
for f in wrfout_*; do
   echo mv $f ${f:0:24}:${f:24:2}:00;
   mv $f ${f:0:24}:${f:24:2}:00;
done
cd -

cd stage/wrf/ctl
for f in wrfout_*; do
   echo mv $f ${f:0:24}:${f:24:2}:00;
   mv $f ${f:0:24}:${f:24:2}:00;
done
cd -
```

## Docker

* Copy the Dockerfiles into the working directory

```
cp i-wrf/docker/lulc/input/Dockerfile* /path/to/working_dir/
```

* Run Docker commands to build the images and push them to DockerHub

### WRF input data
```
docker build -t ncar/iwrf-data:lulc-input-wrf-ctl-d03.docker -f Dockerfile.wrf --build-arg SIMULATION_ID=ctl .
docker push ncar/iwrf-data:lulc-input-wrf-ctl-d03.docker

docker build -t ncar/iwrf-data:lulc-input-wrf-dfw4x-d03.docker -f Dockerfile.wrf --build-arg SIMULATION_ID=dfw4x .
docker push ncar/iwrf-data:lulc-input-wrf-dfw4x-d03.docker
```

### Observation input data
```
docker build -t ncar/iwrf-data:lulc-input-obs-d03.docker -f Dockerfile.obs .
docker push ncar/iwrf-data:lulc-input-obs-d03.docker
```

## Apptainer

The following instructions were run on casper from the stage directory.

Load the apptainer module:
```
module load apptainer
```

### WRF input data

Assumes the wrf directory has subdirectories ctl and dfw4x with the staged WRF files.
```
cd wrf

mksquashfs dfw4x/ input_wrf_dfw4x.squashfs
apptainer sif new input_wrf_dfw4x.sif
apptainer sif add --datatype 4 --partarch 2 --partfs 1 --parttype 3 input_wrf_dfw4x.sif input_wrf_dfw4x.squashfs

apptainer registry login --username MY_USERNAME oras://registry-1.docker.io
apptainer push -U input_wrf_dfw4x.sif oras://registry-1.docker.io/ncar/iwrf-data:lulc-input-wrf-dfw4x-d03.apptainer


mksquashfs ctl/ input_wrf_ctl.squashfs
apptainer sif new input_wrf_ctl.sif
apptainer sif add --datatype 4 --partarch 2 --partfs 1 --parttype 3 input_wrf_ctl.sif input_wrf_ctl.squashfs

apptainer registry login --username MY_USERNAME oras://registry-1.docker.io
apptainer push -U input_wrf_ctl.sif oras://registry-1.docker.io/ncar/iwrf-data:lulc-input-wrf-ctl-d03.apptainer

# change to directory above wrf to create the observation input data volume
cd ..
```

### Observation input data
```
mksquashfs obs/ input_obs.squashfs
apptainer sif new input_obs.sif
apptainer sif add --datatype 4 --partarch 2 --partfs 1 --parttype 3 input_obs.sif input_obs.squashfs

apptainer registry login --username MY_USERNAME oras://registry-1.docker.io
apptainer push -U input_obs.sif oras://registry-1.docker.io/ncar/iwrf-data:lulc-input-obs-d03.apptainer
```
